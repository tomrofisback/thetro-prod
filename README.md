# Thetro Prod

Site vitrine statique de Thetro Prod.

## Publication GitHub Pages

1. Dans le dépôt GitHub, ouvre **Settings** puis **Pages**.
2. Dans **Build and deployment**, choisis **Deploy from a branch**.
3. Sélectionne la branche `main` et le dossier `/ (root)`.
4. Enregistre : le site sera disponible à l’adresse fournie par GitHub, généralement `https://tomrofisback.github.io/thetro-prod/`.

## À compléter

- Ajouter le visuel final dans `assets/thetro-prod-logo.jpg`.
- Remplacer l’adresse e-mail fictive dans `index.html`.
- Ajouter les liens vers les réseaux sociaux, les artistes, les sorties et les réalisations.
- Quand le domaine ou sous-domaine OVH sera choisi, le relier à GitHub Pages via la zone DNS.
